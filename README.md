# iSchool B2G Demo Hub 🚀
> البوابة الموحدة لعروض وأنظمة مشاريع القطاع الحكومي (B2G Projects & Live Demos Portal)

---

## 🌟 نظرة عامة (Overview)

معرض تفاعلي شامل ومتقدم يجمع كافة الأنظمة الرقمية، أدوات معالجة البيانات، ونماذج إدارة العمليات المطورة لمبادرات وزارة الاتصالات وتكنولوجيا المعلومات (براعم ورواد مصر الرقمية **DECI** & **DEBI**) من قِبل شركة **iSchool**.

تم تصميم المنصة لتكون **100% Client-Side** خفيفة وسريعة وتعمل بالكامل في المتصفح، مما يجعلها مثالية للاستضافة السحابية المباشرة والمجانية على **GitHub Pages**.

## 🛠️ المزايا الهندسية والتقنية (Technical Architecture)

1. **أمان البيانات 100% محلياً (Zero External Data Transfer)**:
   - كافة عمليات قراءة ومعالجة جداول الطلاب تتم محلياً داخل المتصفح، دون نقل أو رفع أي سجلات لخوادم خارجية.
2. **استضافة جاهزة على GitHub Pages**:
   - لا تتطلب أي خادم خلفي (Serverless Static Architecture).
3. **محاكي أجهزة مدمج (Interactive Device Frame)**:
   - إمكانية معاينة المشاريع داخل المنصة بشاشات مختلفة (حاسوب مكتبي 100%، حاسوب محمول 1200px، تابلت 768px، هاتف 390px).
4. **تصدير وطباعة حية**:
   - إمكانية تحميل نماذج DOCX وPDF وعينات Excel مباشرة.

## 🚀 النشر على GitHub Pages (Deployment)

1. إنشاء مستودع جديد على GitHub (أو استخدام المستودع الحالي):
   ```bash
   git init
   git add .
   git commit -m "feat: initial B2G Demo Hub"
   git branch -M main
   git remote add origin https://github.com/iabdelrhmaneyad/b2g-demo-hub.git
   git push -u origin main
   ```
2. تفعيل **GitHub Pages**:
   - انتقل إلى **Settings** > **Pages**
   - اختر الفرع `main` والمجلد `/ (root)`
   - سيصبح الموقع متاحاً على الرابط:
     `https://iabdelrhmaneyad.github.io/b2g-demo-hub/`
